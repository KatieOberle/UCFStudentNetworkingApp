# UCFStudentNetworkingApp
Our networking web application will produce a convenient and open space for UCF students to network among their peers. Specifically, our team intends to provide a space where students can connect based on mutual career interests and professional affiliations.

# Features
## Must-have features
* Login/Signup Page
* User authentication via email
* Search with partial matching
* User profile page (Name, major, career interests, contact info, affiliated companies)
* Discussion posts (create, respond, delete (only delete owned posts/replies))
* Network connections
* Moderation (report user)
* Security features (password hashing, user authentication)
## Nice-to-have features
* Mentoring discussion communities
* Community blockers (prove major)
* Enhanced Profile UI (profile photo, private messaging)
* Moderation (key word recognition)
* Recommended profiles (matching via major/classes)
* Advanced security features (data encryption)
* Bookmarks/saved posts
* UCF email-based profile verification
